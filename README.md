# VehicleOrbit

一个 Wallpaper Engine 的 **Web 壁纸模板**：把任意载具模型放进一望无际的灰色无机平面上，五盏顶部点光源照明，镜头锁定视点、可环绕观察，静置 10 秒后自动进入黑屏转场的环绕运镜。

载具名、模型文件、全部可调参数都通过配置文件与 Wallpaper Engine 的壁纸属性面板控制，**换模型不需要改代码**。

## 快速开始

1. 把你的模型命名为 `model.glb`，放进 `wallpaper/assets/`
2. 打开 `wallpaper/config.json`，把 `vehicleName` 改成要显示的名字
3. 打开 Wallpaper Engine 编辑器，把 **`wallpaper/index.html` 拖到 `Create Wallpaper` 按钮**上
4. 应用后如需微调，在壁纸属性面板里改（见下表）

> 也可以不改文件名，直接把 `config.json` 里的 `modelFile` 写成你的实际文件名。

## 模型要求

| 项 | 要求 |
|---|---|
| 格式 | **glTF 2.0 Binary（`.glb`）**，贴图内嵌单文件 |
| 坐标系 | **+Y 朝上**，正面朝 **+Z**（若朝向不同，见下方"模型朝向"） |
| 单位 | 建议米制。程序会按包围盒自动适配相机、灯光与雾的尺度，尺寸不标准也能用 |
| 面数 | ≤ 150k 三角面为宜（常驻壁纸）；贴图总显存建议 ≤ 150 MB |
| 材质 | 标准 glTF PBR（baseColor / normal / occlusion 贴图），不支持自定义着色器 |

### 模型朝向

默认正面朝 `+Z`。若你的模型朝向不同，用编辑器打开 `js/main.js`，改一行：

```js
modelYaw: -0.42,   // 弧度。+Z 为 0；机头朝 +X 用 -Math.PI/2；朝 -Z 用 Math.PI
```

## config.json

```json
{
  "vehicleName": "example",
  "modelFile": "model.glb"
}
```

| 字段 | 说明 |
|---|---|
| `vehicleName` | 显示在右上角钟表下方的名称。**留空则不显示名牌** |
| `modelFile` | 模型文件名。**只写文件名时自动去 `assets/` 找**；也可写相对路径如 `assets/tank.glb` |

启动时读取，`cache: no-cache`，改完刷新即生效。

## Wallpaper Engine 属性面板

| 属性 | 类型 | 默认 | 作用 |
|---|---|---|---|
| 自动运镜 | 开关 | 开 | 静置 10 秒后自动进入运镜循环 |
| 显示时钟 | 开关 | 开 | 右上角时钟（时间 / 日期 / 星期） |
| 显示载具名 | 开关 | 开 | 时钟下方的载具名 |
| 载具高度偏移（%） | 滑块 −8~8 | 0 | 按模型长度的百分比抬高/压低，用于修正不贴地或悬浮过高 |
| 整体曝光 | 滑块 0.55~1.25 | 0.80 | 全局明暗总开关 |
| 灯光强度 | 滑块 0.3~2.5 | 1.00 | 只影响五盏顶灯，调对比度 |
| 载具亮度 | 滑块 0.7~2.0 | 1.38 | 只提亮模型本身，不影响地面与背景 |
| 贴图 UV 映射 | 下拉 | 按导出原样 | 贴图错位时的兜底（上下/左右/双轴镜像） |

**调参顺序建议**：先 `整体曝光`（总亮度）→ 再 `灯光强度`（对比）→ 再 `载具亮度`（只修模型）。三者互不干扰。

## 操作

- **左键拖拽**：围绕载具环绕（视点锁定在载具中心，无平移、无缩放跳变）
- **右侧贴边滑条**：上下拖动调整镜头距离（顶部最近 / 底部最远）
- **静止 10 秒**：自动运镜（黑屏转场 → 近机位 → 等高环绕 → 循环），任意拖拽或滑条操作立即接管

镜头高度有下限保护，无论怎么拖、载具抬高多少，相机都不会沉到地面以下；抬高载具后还能压到更低的角度仰拍。

## 常见问题

**贴图错位 / 上下颠倒**
先在模型属性里试「贴图 UV 映射」的四个档位。仍不对说明模型本身的 UV 有问题，需要在建模软件里重新导出。

**模型悬空 / 陷进地面**
用「载具高度偏移」修正（±8% 内）。相机会跟着载具的焦点移动，抬高后不会穿帮。

**模型太小或太大**
不用管，程序按包围盒自动适配相机距离、灯光高度、雾浓度与地面尺寸。

**右滚轮 / 右键拖拽在 WE 里没反应**
WE 桌面壁纸对滚轮与右键事件支持不稳定，这是已知的平台限制。请用右侧滑条。

**画面一进来就黑屏**
说明模型加载完成但 `assets` 里没有模型文件，检查 `config.json` 的 `modelFile` 是否与实际文件名一致。

## 性能参考（以 16 米级战机、364k 面、33 张贴图为例）

| 项 | 数值 |
|---|---|
| 贴图显存 | 约 108 MB（含 mipmap 约 145 MB） |
| 绘制批次 | 204 个 mesh → 204 次 draw call |
| 常驻内存 | 约 200–300 MB（WE 的 CEF 进程） |

面数或贴图量过大时，建议先在建模软件里减面、把贴图统一压到 1024² 以内。
